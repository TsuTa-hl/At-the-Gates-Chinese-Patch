# 翻译风格

翻译新发现的安全文本或审阅现有中文字符串时使用本指南。

## 设定

- 游戏是一款关于古代晚期、罗马边疆、迁徙民族、部族生存及所谓蛮族派系的 4X 策略游戏。
- 在中文语境中，将其视为围绕迁徙、生存和边疆政治的 `古罗马晚期` / `蛮族部族` 历史
  策略设定。
- 中文应适合历史策略 UI，而非现代休闲应用。

## 语气

- 优先简洁、稳定、有历史依据的中文。
- 避免网络俚语、现代玩笑、过度直译的机器翻译和过分文言化。
- 对命令、成本、要求和警告使用直接的策略游戏语言。
- 角色对话保持自然易读；仅在英文支持时加入轻微时代感。

## UI 与布局

- 按钮标签应简短、面向动作。
- 提示可用完整句，但应足够紧凑以放入面板。
- 中文字符之间不要添加人为空格。
- 在图标、数字、变量和内联标签周围保留可读空格。
- 长英文句必须放入狭窄 UI 时，压缩中文但保留玩法含义。
- 富文本概念链接在链接中文词周围可能出现额外视觉空隙。不得用填充字符补偿；除非
  特定 UI 已证实无标签安全，否则不能仅因美观删除有用概念标签。

## 标签与占位符

除非周围系统明确要求翻译显示术语，下列内容必须原样保留：

- `[TAG]`、`[Tag|KEY]`、`[HOTKEY:*]`、`[COLOR:*]`、`[NEWLINE]`、
  `[BLANK-LINE]`
- 运行时变量、ID、类枚举键、文件路径、URL、版本号、World ID 和生成名称
- 令牌或标签格式要求的标点

组合或富文本模板的参数顺序、结构保留和可复用规则选择由
`translations/composite-text-rules.json` 管理。直接按 `EntryPointId` 和
`RuleId` 查询；用户审查输出不是 AI 输入。模板控制语序、参数绑定或富文本结构时，
优先使用完整显示模板；否则可全局复用已验证的完整格式化片段精确替换。

## 概念链接

- 将 `[显示文本|CONCEPT-KEY]` 视为交互概念链接。准确保留键；仅显示编辑安全时，
  只变更显示文本。
- 修改概念链接标签前，按 `Key` 查询 `translations/concept-key-translations.json`。
  它从静态输入记录每个来源显示词及其已观察到的中文显示词。
- 当相同来源显示词和 `CONCEPT-KEY` 只有一个无歧义中文标签、所有已验证出现位置均为
  仅显示用途且标签结构不变时，优先对完整格式化链接进行键控全局替换。这是复用常见
  术语、短句和标签翻译的常规方式。
- 不得脱离 `CONCEPT-KEY` 全局替换裸显示词，也不得全局替换有多个已观察中文标签的
  键/标签对。此时先检查受影响出现位置，再选择完整模板或限定范围的入口点。
- 任一静态输入变更后，重建并验证概念键映射。

## 数值与数值关系

- 保留数值的正负号、比较、运算、单位和算术含义。除非完整来源模板证明存在转换，
  百分比和倍数必须区分。
- 数值、百分比和倍数优先使用阿拉伯数字，除非显示术语本身要求其他形式。数字与单位
  保持相邻，避免人为中文空格。
- 动态数值在参数顺序、单位位置或语法角色变化时，使用可复用的完整模板或限定范围的
  规则。不得使用会改变数值运算或句子关系的全局片段替换。

## 可接受的剩余英文

除非找到安全的仅显示来源，下列内容可保留英文：

- 生成的角色或氏族名称
- 如 `Clan <Name>` 的生成通知前缀，直到隔离出安全的仅显示来源
- World ID
- 版本号
- URL 与文件路径
- 热键标签和技术标记
- 作为标题/名称而非普通散文出现的产品名 `At the Gates`
- 尚未用独立映射隔离出逻辑敏感来源的非部族派系名和标签

不得仅为风格一致而强行将这些内容翻译成中文。
