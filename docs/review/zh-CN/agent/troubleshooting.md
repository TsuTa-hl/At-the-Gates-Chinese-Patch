# 故障排除

| 症状 | 首先操作 |
| --- | --- |
| 源捕获拒绝活动补丁 | 运行事务卸载器，再从已恢复 Steam 原版重新捕获。 |
| 构建保留旧补丁不变 | 检查失败的暂存契约；不得把暂存输出手动混入 `patch/`。 |
| 安装器发现先前或中断事务 | 让卸载器恢复；验证成功前保留清单和 `_ChinesePatchBackup`。 |
| 卸载器恢复文件后在显示存档改名通知时出错 | 空 `RenamedSaves` 集合有效：帮助程序必须接受它并直接返回，不显示对话框。在卸载脚本测试中覆盖此路径。 |
| 补丁专有文件在安装后被改动 | 不得强制删除。保留清单/备份，并判定该文件是否为玩家或 MOD 内容。 |
| 锁定依赖恢复无法访问 NuGet | 先解决锁定恢复；统一门禁现在会在创建游戏事务前停止，不要手动恢复游戏文件。 |
| 烟测失败 | 验证门禁会自动恢复门禁前文件。修复前阅读匹配的崩溃风险专题。 |
| 发布推送租约失败 | 获取并检查新的远程发布分支、同步 `main`、重跑门禁后再发布。 |

启动/内容、运行时/资产或托管重写失败时，使用 `crash-risks/` 下的相应专题。
