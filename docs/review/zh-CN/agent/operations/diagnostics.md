# 运行时与资源诊断

仅在调查性能、内存、网络、窗口捕获或运行时渲染器时读取本文件。

- 使用 `tools\Measure-AtGResourceUsage.ps1` 获取进程内存、句柄和网络相邻遥测。
  保留精简 JSON/文本摘要，不要保存原始跟踪。
- 将 32 位游戏、桌面客户端和构建工具视为独立进程。未测得进程身份时，不得把桌面
  应用内存归因于游戏。
- DynamicCjk 的上限是 8 页 1024x1024 RGBA 图集（32 MiB）。缺失字形必须产生
  RuntimeText 诊断，而非 SpriteFont 崩溃。
- 浏览器或网络捕获需选择加入。局部结构化结果足够时，避免反复下载、恢复或上传
  大型截图。
