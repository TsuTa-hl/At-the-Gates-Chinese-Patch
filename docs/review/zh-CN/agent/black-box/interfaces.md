# 接口测试覆盖（压缩审查译本）

> 原文包含固定存档的历史坐标、单项回放和逐次证据。本副本翻译可复用的接口验收
> 规则；具体历史结果以原始 `docs/agent/black-box/interfaces.md` 和场景 JSON 为准。

使用场景注册表获取坐标、设置状态和机器 ID。本文件定义检查内容及界面何时可视为
已覆盖。

## 坐标验证门禁

- 用户截图能确立已知缺陷与意图控件，但**不能**确立可运行的 `X`/`Y` 对。场景坐标
  使用 2560 x 1440 harness 参考空间，必须在同一存档和界面上以当前、带光标标记的
  完整客户端捕获证明。
- 设置点击和悬浮点都要校准。只有请求的目的地标记（如外交界面）可见时，设置点击
  才有效；帧指纹变化本身不够。
- 悬浮校准必须显示命名控件及其自身提示。附近地块详情、卡片主体、通知或标题均不能
  代替。永久保存点位前，在当前交接中记录捕获尺寸、存档名、参考坐标、标记结果和
  稳定目标身份。
- 缺少证明时记录 `UncalibratedCoordinate` 并停止。它既不是本地化通过也不是失败，
  不得用它通过反复截图猜测调坐标。
- 固定存档回放分两阶段：先证明设置目的地（氏族、外交、选定领袖），再证明每个
  悬浮目标及其提示。仅稳定绝对鼠标轨迹不足够。

## 外交

- 选择器按钮、其悬浮提示、选中小部族详情面板和 Relationship Level 提示是独立界面。
- 工具提示中的名称可能被拆为冠词和裸部族名绘制节点。因此按钮保留完整名称映射，
  提示可使用拆分名称/冠词回退。
- 回滚验证未打开外交面板时，仅是回滚证据，不是新的外交 UI 回放或坐标校准。

## 主菜单、加载与重载

- 主菜单烟测检查完整窗口且没有新的崩溃/日志事件。
- `Screen_ChooseFaction.Update` 从按钮文本前四字符派生派系键；十个可玩派系的
  `<name>` 与 `city/name` 配置值必须保持原始逻辑字符串，可见中文来自运行时显示
  映射。新游戏点击在当前客户端几何上可见证明部族选择目的地前不能通过。
- 固定存档从主菜单加载面板加载；除非游戏内重载正是被测项，否则不要从暂停菜单
  替代。
- 加载面板应本地化按钮/提示，但 World ID、版本和生成存档标签可保留。
- 游戏内重载生命周期在一个进程中反复重载同一固定存档；只有渲染器、加载生命周期、
  Game/ElfTools 重写或存档行为变更时才是 FullRegression。

## 知识界面

- 测试场景选定的可见节点、状态行、升级图标、页脚、显示全部和关闭控件。
- 确认不存在职业/纪律原始键、`Cannot`/`Already` 片段混合、未本地化要求和损坏富文本
  链接。
- 存在二级提示时，嵌套概念悬浮必须保留高亮显示词和有效二级提示。

## 氏族界面、特质与氏族列表

- 从主循环打开氏族界面，测试操作按钮、卡片详情和所有可见特质图标。
- 随机六点特质发现已延期并禁用。用 `clan-trait-verification.json` 记录刻意检查的
  特质 ID 与存档。
- 范围包括 92 个个性和 14 个非个性特质。只有特质自身名称和效果/描述均可见确认时
  才通过；肖像、卡片主体、通知或氏族详情卡都不能代替。
- 氏族列表默认只测试首行标题悬浮及 Level 二级提示；更深嵌套路径需明确请求。
  Clan、Discipline、Level、Upgrades 等概念链接应显示本地化词且保留有效概念键。

## 主循环、地形与资源

- 仅测试受影响的 HUD、系统、操作、资源、通知与选中单位控件；默认不扫描无关已通过
  控件。
- 选定定居点/单位时，检查 Pack Up、移动、跳过及变更可能影响的当前可见操作。
- 地形测试点击/悬浮活动场景所需的每个不同可见对象，并检查右下说明和左侧详情面板。
- 已归档的 `TileHoverSweep` 是探索记录；不再选择或维护生成的 91 格运行时扫描。用户
  确认具体地形/资源缺陷时，以其固定点场景和现有边界清单为检查表，不把旧扫描证据
  当作新覆盖会话。
- 固定存档地形/资源悬浮和上下文特质心情案例需用户确认缺陷并授权指定运行后才能执行。
  仅使用已批准绝对坐标及同一存档；重复创建新世界仍须单独用户确认和手动确认流程。
- 人工审查或地形/资源翻译变更前运行
  `tools\Test-TerrainTooltipBoundaryCoverage.ps1`。它验证源名称、定义的地形/资源描述
  和运行时资源/传闻提示模板；标为 `TODO` 的火山描述仍由来源定义，不能当作缺失运行时
  观察。
- 随机地形、氏族、通知或命令暴露缺陷时，保存状态并用同一存档修复/复测；绝不边追
  一个缺陷边重新掷世界。

## 帮助与宗教

- 帮助测试仅覆盖请求的文章/页面序列；过度使用 `Escape` 可能先关闭文章、再关闭帮助
  面板、最后打开暂停菜单。
- 宗教测试使用指定固定存档并检查标题和每个列出选项。保留逻辑 ID，同时本地化稳定
  显示名。

## 完成证据

记录场景 ID、设置/存档、目标点、可见结果、崩溃日志状态、时间和任何限制。只有在此
文本记录进入清理交接前才保留截图。
